# Contributing

Gracias por colaborar. Para proponer cambios:

1. Crea una rama clara: `feature/<descripcion>` o `fix/<descripcion>`.
2. Añade tests y documentación para cambios relevantes.
3. Abre un Pull Request hacia `cloud-pentest` si es para este fork; mantenlo pequeño y con descripción.

Comportamiento esperado en PRs:

- Referencia la autorización/legal si añades herramientas de prueba.
- Incluye un archivo `runbook.md` si introduces automatizaciones.
